**Rule.** A material made per tile, per mesh or per instance batch is a clone of ONE template graph, or uses the same node objects. What differs per tile goes through the material (an object-update node reading `material.userData`, or a plain material property) or through a geometry attribute. It never goes through a node bound to that tile's own texture, buffer or uniform object. Count before you share: `debug/perf5Run.js` `buildClusters()` (with debug/bootTimeline.js as the init script) lists every main-thread node build after a moment, by material and object. A build that repeats per tile or per mesh with the same material name is this rule's case.

**Why.** three r187 keys its node-build cache by node ids (`customProgramCacheKey` hashes the graph's node ids, not its WGSL). A material made from fresh nodes builds the same shader again on the main thread, the first time it draws, inside that frame. On the quiet laptop (2026-11-26, docs/perf/QUIET_2026-11-26.md), every 45 s police drive from the station had two such cases:
- the Chenaie timber playground's three fading pieces (viewer/parkKit.js fadeCopy: `instancedBufferAttribute(attr)` bound to each mesh's buffer): 3 x 24-31 ms of builds in one frame, the drive's worst frame (117-164 ms);
- each landing tile's asphalt (viewer/roadPaint.js asphaltMaterial: the marking atlas texture and two uniforms built into the graph): 26-32 ms in the frame the tile first drew (52-66 ms frames).

Fixed behind `?kitfadeshare=old` and `?asphaltshare=old`. The park kit now has one fading copy per slot material, with the fade value as the geometry attribute `kitFade`. The asphalt is one template per atlas kind, and each tile is a clone. Measured, 3 + 3 fresh-tab drives alternated: worst frame 116.7 / 150 / 116.7 ms -> 66.6 / 66.7 / 83.3 ms, frames over 100 ms 1 / 1 / 1 -> 0 / 0 / 0, the playground's builds 84-112 -> 17-20 ms, asphalt builds while driving 2 x 27-32 ms -> 0. The steady per-frame CPU (12.1-12.5 ms) is unchanged.

**Not yet shared** (same rule, the next cases in the same drives): each tile's terrain (`ground:textured`, 18-22 ms a landing: its cover / ortho textures and bounds uniforms are in the graph); the walls' fading copy in the shadow pass (`SH:...:fade buildings-walls`, 29-31 ms); the rail materials' first build (41-61 ms, once a session, not per tile).
