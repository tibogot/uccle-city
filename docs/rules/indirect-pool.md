**Rule.** A CPU-written indirect-draw record (a multi-draw kit view's chunks, a cell-culled tile mesh's cells, any new user) lives in the page's ONE indirect buffer, viewer/indirectPool.js. Take a slot with `const s = indirectPool().alloc(n)`, write the records into `pool.array` at `s.base * 5`, upload them with `pool.touch(s, rec, n)` (update ranges, never the whole buffer), draw with `pool.bind(s, geometry, offsets)` where the offsets are BYTES from the pool's start, `(s.base + rec) * 20`, and `pool.free(s)` on the geometry's dispose. Never keep the attribute or its array in a field: a growth makes a new one (same bases, same offsets) and re-points the bound geometries, so read `pool.array` / `geometry.indirect` each time. `new THREE.IndirectStorageBufferAttribute` appears only in indirectPool.js, the `?indpool=old` branches, and the GPU-written args (compute shaders that count into the args with atomics: foliage/grass.js, grass/grass.js, foliage/plants.js, birds/skyFlocks.js). A new GPU-written user is added to the gate's exception list with its reason.

**Why.** Chrome's Dawn on D3D12 (the owner's Windows laptop) validates the args of indirect draws with compute work encoded before each render pass, batched per indirect buffer; Toji measured ~3 ms of a 6 ms pass for 412 indirect draws from separate buffers and ~10 us once they were packed into one. On 2026-11-23 debug/indirectCount.js counted, in the main scene pass, ~2,300-2,500 indirect draws from 55-69 distinct buffers at the Saint-Job street view and in the police drive: one buffer per multi-draw view (~55 views) and one per cell-culled tile mesh (4 a tile). The shadow cache's redraws used up to 36-41. Three r187's `setIndirect(attribute, offsets)` already takes byte offsets into a shared attribute, so one buffer costs only a base offset per user. GPU-written args stay apart: their compute nodes bind the attribute as storage, and a pool growth would rebuild them.

**Measured** (claude/indpool, 2026-11-23, preflight YELLOW): distinct indirect buffers in the main pass 65-69 -> 3 at the Saint-Job street view and 55-63 -> 3 in the police drive (shadow redraws 36-41 -> 1). GPU-bound wall time of a full-scene render (debug/indirectBench.js, 2x target, 8 alternated page loads) about -0.7..-0.9 ms at the street and 45 m views; three's timestamp queries do not see Dawn's validation, so measure with `wall`, not `ts`.
