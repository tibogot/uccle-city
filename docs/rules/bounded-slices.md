**Rule.** Work that grows with what streams in (a tile, a landmark, a field) runs in bounded slices while the player plays (<= ~4 ms of main thread a slice: compile slices, CPU-copy drops, scripted ground builds, a tile's placement steps a frame apart), or only when its result can be seen (the grass field only while blades can show); a warm-up goes through the path the real draw takes (shadow-warm stand-ins are sun-cache movers, or they warm nothing). Round 2 (provisional extension): a warm-up covers every material a mesh can draw with (its distance swaps too: the kit walls' near + far) and every pass (shadow included, a retire's new fading copies too); a per-tile mesh of a shared material keeps three's node build shared (an InstancedMesh: geometry attributes + instance buffers <= 8, else per-instance data read by referenceAttribute); a copy made for a worker is transferred, never cloned again.

**Why.** the falcon flight hitched 50-300 ms: the Square des Heros' ground in one 300-350 ms task as its tiles came in, the heap-drop check's bounds in 24-58 ms tasks, a tile's stops-to-plants step in one 25-90 ms frame, three's 8 ms compile slices + a node-build stage on top of the frame, the grass field re-baked (35-45 ms) 80 m up, and shadow-warm stand-ins the sun shadow cache never drew (the landmarks' LOD fading copies then built their shadow shaders on screen: 44-52 ms) (claude/falconstutter); round 2: a retiring tile's far kit-wall fade copy built its shadow shader on screen (31-56 ms), every tile's street-life box mesh built its own shader (11 attributes: object specific, 8-9 ms), the gardens step 18-40 ms, the hero collider poll 37-66 ms (claude/falcon2)
