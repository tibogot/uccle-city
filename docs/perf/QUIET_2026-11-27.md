## 1. The hitch when walls' shadows fade in (rule fade-shadow-warm, row fadeshadow)

Causes, found with a per-camera build probe on the police drive:
- lodFade.js fadeProxies() makes a stand-in only for a fading copy that does NOT exist yet; the shared walls' copy is
  made under the boot cover by the held fade, and the play loader's tiles (holdFast) compiled theirs for the scene pass
  only: "walls:fade" was never warmed in the sun's pass. Fix: fadeShadowProxies(), one stand-in per (copy, layout).
- landmarks' own shadow warm-ups (police station ...) warmed one stand-in per new copy on its first mesh: another LOD level
  with another layout built on screen at its first LOD fade (police: 9 builds, 90 ms, a 160 ms frame ~9 s in).
- the night lamps' warm-up skips fading casters: "walls:fade" in a spot's pass, 87 ms in one frame.
- under the play loader the main loop renders one rAF in three, so warmShadows' 2-rAF batches were removed before any
  shadow pass drew them (the stand-in marked warmed, never built). Fix: a batch stays until sunCache.stats.frames moved
  by 2 (?shadowdrawn=old).

## 2. Draws per tile (rule tile-draws-merged, row fewerdraws)

debug/tileDraws.js at the spawn view: 7 full tiles, 79 main-pass draws = 11.3 per tile (14-24 for the 4 in view).
A full tile draws: buildings walls / walls-kit (cut or far) / roofs / roofs-flat / details (5), roads asphalt / concrete /
grass / paint / pits (5), terrain (1), and features: tram (wire, poles, pole arms, platforms, platform edges, rails),
railway, street life (boxes, windows), fuel (5 per station), bollards. Far tiles: 2 each (buildings + ground), 28.
- Done: a tram tile's platform slabs + kerb edges are one mesh, colour / roughness per vertex, one shared material
  (was two fresh materials per tile): -1 draw main pass, -1 sun pass per tram tile (?tramplat=old). Look: the same view
  old vs new, the platform crop 0.8 % of pixels > 20 (the whole frame's drift: clouds, a pedestrian).
- Not done (each a redesign, reported): the per-tile kinds are one material each, so the real lever is ACROSS tiles:
  the same shared material (walls, roofs, details, asphalt, concrete, terrain template, far buildings) drawn once per
  tile. Merging tiles needs one vertex / index arena per material with per-draw fade and cell culls (the tile fade is a
  per-object uniform, cellCull's indirect records are per mesh): ~44 -> ~11 draws for 4 tiles in view, but it changes
  streaming, fades and disposal. tram-poles / tram-pole-arms stay instanced (garlands and colliders read their matrices).
